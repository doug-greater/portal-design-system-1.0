Rules

Footer bar: attaches to the table's bottom (shares its border, --p-surface-alt fill, border-radius: 0 0 var(--r-card) var(--r-card)). Left = result range Showing 1–50 of 3,600 in --p-muted with bold figures; right = rows-per-page select + pager.

Pager: 30px cells, radius 6px. Active page is a solid --p-action (ink) chip — you navigate to a page, so it's wayfinding like the active tab, not selection; others are ghost (hover --p-surface-tint). The rows-per-page select keeps its blue focus ring (control focus stays blue). Prev/next are bordered icon buttons that disable at the ends. Collapse long ranges with an ellipsis, always keeping first, last, and the current ±1.

Page size: 25 / 50 / 100. Default 50 — matches the Filter Menu's 50-row search cap so the two never disagree.

Paging vs. Load more: use numbered paging for tables operators scan and jump around (Products, Accounts, Users). Use Load More for feed-like or append-only lists where position doesn't matter. Don't use both on one surface.

Numerals & controls speak mono (Cockpit 1.12 · clarified 1.12.2). The count readout (Showing 1–50 of 3,600), the page numbers, ellipsis, rows-per-page select, and the Load-more button all render var(--font-control) — a paginator is the machine reporting result-set state to the operator (a readout of data), not prose. The entity names in the body rows (product / account) stay Inter — a name is content wherever it appears. The count noun ("accounts", "changes") is a unit label, so it rides with the mono readout, not the Inter names.
