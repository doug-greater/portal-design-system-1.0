Live View (1.10 §A). A joint map + table of every rep's route for today — a "live surface", so there's deliberately no date filter. The Status Select is leftmost and lenses the table only; identity facets scope both map and table. The map is monochrome (gray routes) until a route is focused (blue + scaled pins + others dimmed). Pins encode the five live statuses via .g-live-pin; each rep has one pulsing .g-live-rep dot (stilled under reduced motion).

Five statuses. Planned · In Progress (pulsing gr-livedot) · Complete · Incomplete = RED (started, never submitted, and a later stop began — the real problem this surface exists to surface) · Skipped (deliberately quiet). Auto-refreshes every 60s, paused while the tab is hidden, preserving map center/zoom. An App-Shell lv-nav-alert-dot mirrors the Incomplete count in every sidebar state (§B).
